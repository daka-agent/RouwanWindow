# 《窗外》· RouwanWindow

> 《玉兔的世界》的背面。同一扇窗，从里面看出去。
> 观众终于站到它身边了，但也从此无法与它对视。

**线上**：https://daka-agent.github.io/RouwanWindow/
**姐妹作**：[玉兔的世界](https://daka-agent.github.io/YutuWorld/) · [肉丸值白班](https://daka-agent.github.io/RouwanDayshift/)

单文件 `index.html`（约 609 KB），纯静态，零外链，无 AI、无交互、无 localStorage。
真实时间驱动：油灯光（灯油数据来自 365 天排班）、窗玻璃雾（玉兔擦）、
地球地相（潮汐锁定，地球永挂同一个地方）、镜头灰（永不清零）。

空窗不是失败——打开页面多半看到空屋，那是它的性格。
